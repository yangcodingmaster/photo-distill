# 结构索引 · Structural Index

选图形语言之前，先认照片的**结构类型**，再看同类结构曾经怎么解。

> **Borrow the move, not the composition. 学那步棋，不抄那盘棋。**
> 每张海报必须是一个新的图形语言（SKILL.md §六）——这张表教的是
> "这类结构该往哪个方向蒸馏"，不是可复用的构图模板。

| 照片的结构类型 | 蒸馏的那步棋 | 示例 |
|---|---|---|
| 单一物体，夜景 | 物体拆成三四个印刷记号：墨块＝夜、细线＝柱、圆点＝灯 | [NO. 009](README.md#no-009--夜的墨块--the-block-of-night) |
| 均质的场 + 少量异常点 | 场与异常统一成**同一种符号**；异常＝场让开的空处，边界自己稀疏 | [NO. 020](README.md#no-020--均质点场--三处异常--a-uniform-field-three-anomalies) |
| 软物无形（云/雾/水汽）+ 一个清晰主体 | 软物化成无边界墨气，**全张只留一个硬边**给主体 | [NO. 022](README.md#no-022--无边界墨气--全张唯一的硬边--one-hard-edge) |
| 密度随距离渐变（海面/地面肌理） | 只画密度梯度（笔宽与浓度单调变化），边界线**自己浮现** | [NO. 023](README.md#no-023--密度梯度场--the-line-appears-by-itself) |
| 近糊远清（浅景深里的框/窗） | 框不画，只留框造成的**浓度差**；唯一硬边给最远的清晰物 | [NO. 024](README.md#no-024--一方冷亮从里面让开--a-cold-rectangle-and-the-light-that-steps-aside) |
| 两种光源同框（发光体 vs 照明体） | 两种光两种符号：内透＝无晕硬边小块，投射＝亮核 + 洒开的暖痕 | [NO. 025](README.md#no-025--内透的光与投射的光--light-from-within-light-cast-down) |
| 几何框架 + 一块色 + 一片光 | 框架按实测画线；色只住在它真实所在的格里；光是没有边的淡 | [NO. 026](README.md#no-026--窗格线一格绿洒地的光--a-grid-one-green-pane-light-on-the-floor) |
| 人物微小、环境有手感 | 微缩人＝头点 + 身笔；环境材质换成印刷语言（油画棒拖痕） | [NO. 004-B](README.md#no-004-b--油画棒--测距图--crayon-drag--measurement) |

通用判据不变：**如果观者还在数花瓣，画的就仍是物体**——不管哪种结构类型，
蒸馏的终点都是关系，不是简化的物体。每对示例的完整推演见 [README.md](README.md)。
